# 어린이 철학 웹 시제품

초등학생부터 중학생까지, 상황을 보고 선택한 뒤 다양한 관점을 만나 다시 생각해 보는 첫 에피소드 시제품입니다.

## 웹 미리보기

Node.js 22 이상이면 실행할 수 있습니다. 외부 패키지를 사용하지 않으므로 의존성 설치는 필요하지 않습니다.

```bash
npm run dev
```

서버는 기본적으로 `0.0.0.0:3000`에서 실행하며 `HOST`와 `PORT`로 주소를 바꿀 수 있습니다. 개인 개발 환경에서는 브라우저로 로컬 포트 3000에 접속합니다. 클라우드 온보딩 화면은 로컬 주소의 웹 미리보기 링크를 지원하지 않으므로, 이 환경에서는 로컬 요청과 브라우저 자동화로 동작을 검증합니다.

```bash
HOST=127.0.0.1 PORT=3001 npm run dev
```

## 빌드와 검증

```bash
npm run build
npm test
```

브라우저 검증은 Python Playwright와 Chromium이 있는 환경에서 개발 서버를 켠 뒤 실행합니다. 현재 클라우드 환경에서는 이 도구를 사용해 전체 체험과 모바일 화면을 검증했습니다.

```bash
python3 tests/browser_smoke.py
```

스크린샷과 검증 요약은 Git에서 제외되는 `test-results/`에 생성됩니다. 이 검증은 실제 아이를 대상으로 한 이해도·흥미 검증과 구분합니다.

빌드는 `public/`의 정적 파일을 `dist/`로 복사하고, `docs/`가 있으면 `dist/docs/`에도 복사합니다. 대본 디렉터리가 없어도 웹 빌드는 실행됩니다. 빌드 결과는 다음 명령으로 미리 볼 수 있습니다.

```bash
node scripts/server.mjs --dist
```

웹 화면은 `/`에서, 대본·편집 가이드·로드맵은 `/docs/<파일명>.md`에서 엽니다. 첫 에피소드 대본 경로는 `/docs/episode-01.md`입니다. 개발 서버는 저장소의 `docs/`, 빌드 서버는 `dist/docs/`만 문서 경로로 제공합니다. 서버를 코드에서 가져올 때는 `createStaticServer({ rootDir, docsDir })`로 문서 디렉터리를 명시해야 하며, `docsDir`을 지정하지 않으면 `/docs/` 요청은 404를 반환합니다.

## 시제품 범위

현재 범위는 첫 철학 에피소드의 상황 소개, 선택, 관점 카드, 웹 활동, 다시 선택하는 흐름과 개인 생각 기록입니다. 영상은 대본과 웹 속 장면으로 확인하며 완성된 영상 파일은 아직 없습니다. 기록은 현재 브라우저의 로컬 저장소에 저장됩니다.

## 파일과 저장 방식

- `public/`: 웹 화면, 스타일, 상호작용 코드와 정적 자료
- `docs/`: 에피소드 영상 대본과 콘텐츠 기획 자료
- `scripts/`: 정적 서버와 빌드 스크립트
- `tests/`: 자동 검증

선택과 생각 기록은 다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 기록도 삭제됩니다.

## 공개 호스팅: GitHub Pages

정적 빌드 결과 `dist/`를 배포합니다. JavaScript와 그림·스타일·문서 링크는 상대 경로를 사용하므로 GitHub Pages의 프로젝트 경로에서도 열립니다. 공개 빌드에는 영상 대본·편집 가이드·로드맵이 포함되며, 브라우저에서 읽을 수 있는 HTML 문서와 원본 Markdown을 제공합니다.

`.github/workflows/pages.yml`은 `main`에 푸시하거나 수동 실행하면 테스트와 빌드를 거쳐 Pages에 배포합니다. 저장소의 **Settings → Pages → Build and deployment → Source**는 **GitHub Actions**여야 합니다. 최초 배포 완료 후 GitHub가 반환하는 Pages 주소를 확인하고 공개 체험을 검증합니다.

배포에 필요한 GitHub API 접근은 `api.github.com`, 공개 사이트 확인에는 `hyeonmini.github.io` 접근이 필요합니다. 클라우드 환경 설정의 게시와 GitHub Pages의 웹사이트 배포는 별개의 작업입니다.
