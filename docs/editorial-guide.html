질문하는 철학: 편집 기준

# 질문하는 철학: 편집 기준

아이의 생활에서 출발해, 서로 다른 생각을 정확히 만나고, 자신의 이유를 만들거나 수정하게 한다. 학설을 외웠는지, 어른의 결론을 골랐는지, 신앙을 가졌는지를 평가하지 않는다.

이 문서는 콘텐츠 기획과 원전 위치를 정리한 편집 초안이다. 아래 장절은 문헌 지식에 근거한 참고 위치이며, 이번 제작에서 온라인 원문 검색이나 특정 한국어 번역판의 문장 대조를 실행한 것은 아니다. 실제 인용문을 사용하기 전에는 사용 판본과 번역문을 대조하고 기록한다. 아동 이해도 검증과 종교·철학 전문가의 외부 검토도 아직 실시하지 않았다.

## 연령을 조절하는 방법

질문을 특정 나이가 될 때까지 금지하지 않는다. 같은 질문에서 사건의 복잡성, 문장 길이, 추상화 정도, 기록 부담을 조절한다.

| 대상 | 기본 방식 | 첫 에피소드 조정 | 피할 것 |
| --- | --- | --- | --- |
| 초1~3 | 그림·짧은 상황·구두 설명. 한 번에 한 질문. 어른이 읽어 줄 수 있다. | 칩을 직접 세고 세 역할을 설명한다. 관점 이름을 외우게 하기보다 ‘누구의 일을 못 봤을까?’를 묻는다. 글쓰기 대신 말·그림을 허용한다. | 긴 설명, 돈 비율 계산 평가, 어른 답 따라 말하기 |
| 초4~6 | 서로 그럴듯한 이유가 충돌하는 사건, 반례 찾기, 선택 전후 비교. | 기여·참여·필요·약속을 서로 다른 이유로 구분한다. 숨은 정보를 읽고 배분이나 이유를 다시 제안한다. | 선택으로 성격·도덕성 판정하기, 수정 강요 |
| 중1~3 | 권력·제도·평가 기준·정보의 신뢰성까지 확장. | 누가 ‘기여’를 정의하는가, 말할 기회가 같았는가, 사전 계약이 있으면 어떻게 달라지는가, 노동 대가와 상금은 같은가를 묻는다. | 논증 능력을 어려운 용어 사용량으로 평가하기 |

나이는 참여 가능성을 판단하는 참고일 뿐 발달 검사나 진단 기준이 아니다. 개인의 독해·경험 차이를 반영하고, 특정 경험이나 감정을 공개하게 하지 않는다.

## 종교와 철학을 다루는 원칙

1. **전통을 계산 공식으로 만들지 않는다.** ‘서양은 경쟁, 동양은 조화’, ‘불교는 욕심을 없애라’, ‘이슬람은 기부하라’처럼 하나의 문장으로 전체를 대표시키지 않는다.
2. **설명과 권유를 구별한다.** ‘이 전통에서는 이렇게 이해한다’고 소개하고, 그 전통을 믿어야 활동을 완료할 수 있는 구조를 만들지 않는다. 믿음·비믿음·판단 유보 모두 참여할 수 있다.
3. **각 전통의 고유 맥락을 남긴다.** 종교 가르침에는 신앙·예배·공동체·실천의 맥락이 있다. 오늘의 생활 조언으로 활용하더라도 맥락을 지우거나 같은 말을 한 것처럼 합치지 않는다.
4. **전통 내부의 차이를 인정한다.** 시대·지역·학파·교파에 따라 해석이 다를 수 있다. 하나의 해석을 소개했다면 그 범위를 표시한다. 차이 자체를 우열의 근거로 삼지 않는다.
5. **원전 설명과 현대 응용을 따로 표시한다.** 원전의 등장인물·제도·소유 관계와 현대 이야기의 조건이 다르면 명시한다. 응용 질문은 제작진이 만든 질문임을 밝힌다.
6. **신앙을 개인 정보로 취급한다.** 종교 선택, 가족 소득, 상처 경험을 입력하거나 공개하게 하지 않는다. 필요한 경우 허구의 인물·상황으로 논의한다.
7. **질문을 열어 두면서 피해를 흐리지 않는다.** 차별·폭력·동의 없는 정보 공개의 영향을 설명한다. 모든 행위가 취향에 따라 똑같이 타당하다고 가르치지 않는다.
8. **기부·복종·용서를 착함의 증명으로 쓰지 않는다.** 공동 재산에는 당사자의 의견이 필요하다. 거절과 경계를 표현하는 선택도 탐구한다.

동서양과 종교를 넓게 다룬다는 목표는 매 편에 모든 전통을 넣는다는 뜻이 아니다. 해당 질문과 관련 있는 관점을 소수 선정하고, 시리즈 전체에서 실제 다룬 전통·지역·시대와 아직 다루지 않은 영역을 확인한다. 유교와 도교 등은 철학·종교의 경계가 맥락에 따라 달라지므로 한쪽 범주로 단정하지 않는다.

## 출처 관리 원칙

- 아이용 설명도 원전의 주장과 모순되면 안 된다. 쉬워진 문장과 정확한 문장은 양립해야 한다.
- 직접 인용은 따옴표로 표시하고 실제 사용한 번역판·번역자·출판 연도·쪽수 또는 장절을 기록한다. 번역자의 표현을 제작진 창작 문장으로 취급하지 않는다.
- 요약은 요약이라고 표시한다. 여러 구절을 합친 문장을 하나의 실제 인용처럼 만들지 않는다.
- 철학은 작품·권·장과 가능한 표준 번호, 종교 문헌은 경전·장절을 우선 기록한다. 웹 주소만 출처로 남기지 않는다.
- 출처 파일에는 원전 위치, 사용 판본, 원문·번역문 대조 여부, 해석 자료, 응용 범위, 검토자를 분리한다. 아직 확인하지 않은 필드는 미확인으로 남긴다.
- 논쟁적인 해석은 신뢰할 수 있는 해설·연구 자료와 함께 검토한다. 외부 검토를 받았을 때만 검토자의 역할·검토 범위를 기록한다.
- 생성형 도구가 제시한 명언·장절은 출처가 아니다. 실재하는 문헌과 대조되기 전에는 직접 인용으로 공개하지 않는다.
- 사용한 번역·그림·음악·폰트의 이용 조건을 확인한다. 오래된 원전의 저작권 상태와 현대 번역·녹음의 저작권 상태를 구별한다.

## 에피소드 01: 관점 카드 원전과 응용

상금 이야기는 전체 로드맵 4단계 ‘공정함과 책임’의 첫 사건이다. 01은 파일·제작 식별자이며 로드맵 순서와 달리 첫 구현으로 선택했다.

공통 아이용 안내: **“옛 생각을 빌려 우리가 만든 질문이야. 이 전통들이 우리 상금의 배분법을 정해 준 것은 아니야.”**

### 1. 아리스토텔레스 — 무엇을 기준으로 나눌까?

**참고 원전 위치:** 아리스토텔레스, 《니코마코스 윤리학》 제V권 제3장, 베커 번호 1131a–1131b. 분배적 정의와 비례 관계를 다루는 부분이다.

**원전 설명:** 공동의 명예·재화 등을 분배하는 정의를 비례 관계로 설명한다. 무엇을 자격 또는 가치의 기준으로 볼지는 정치 공동체마다 다르다고 논의한다. 현대 공동 프로젝트의 노동시간이나 소프트웨어 기여도에 대한 배분 공식을 제시하는 장은 아니다. 고대 정치 공동체의 참여 범위와 위계는 오늘의 동등한 참여 원칙과도 다르다.

**현대 응용:** 이번 콘텐츠는 기준에 비례한다는 생각을 ‘코드·그림·테스트와 홍보가 어떤 기여를 했는가?’라는 질문으로 연결한다. 기여라는 기준은 제작진이 선택한 응용이며, 기여의 측정 방법도 아이들이 다시 질문할 대상이다.

**아이용 카드:** “아리스토텔레스는 함께 나누는 재화를 어떤 기준에 비례해 나눌지 생각했어. 이 생각을 우리 게임에 적용한다면, ‘더 많이 기여했다’는 말을 무엇으로 판단할지 먼저 이야기해야 해. 세 역할은 각각 게임에 어떤 도움을 주었을까?”

**금지되는 요약:** ‘아리스토텔레스는 많이 일한 순서대로 주라고 했다’, ‘코딩이 가장 중요하다’, ‘정확한 작업 시간만 알면 정답이 나온다’.

### 2. 묵자와 묵가의 겸애 — 빠뜨린 친구는 없을까?

**참고 원전 위치:** 《묵자》 〈겸애 상·중·하〉, 통상 편차 제14~16편. 판본에 따라 장 표기가 다를 수 있으므로 한자 편명과 함께 확인한다.

**원전 설명:** 자기 자신이나 자기 집단의 이익만 좁게 챙기고 다른 사람·집단에 피해를 주는 태도를 비판한다. 다른 사람과 집단도 두루 돌보고 서로 이롭게 하는 방향을 제시한다. 모든 재화를 반드시 같은 액수로 지급해야 한다는 산술적 동일 배분 이론으로 단순화할 수 없다. 《묵자》는 묵자와 묵가의 전승이 담긴 문헌으로 다룬다.

**현대 응용:** 내 친분 때문에 특정 인물의 일만 크게 보는 것은 아닌지, 세 사람의 사정과 목소리를 두루 들었는지 확인하는 질문으로 연결한다.

**아이용 카드:** “묵자는 자기 편만 챙기지 말고 다른 사람의 삶과 이익도 두루 돌보자고 했어. 이 생각을 빌려, 상금을 이야기할 때 셋 모두의 바람과 이유를 들어보자. 누군가의 일을 우리가 놓치고 있지는 않을까?”

**금지되는 요약:** ‘겸애는 모두에게 정확히 같은 돈을 주는 것’, ‘동양은 개인의 기여를 중요하게 여기지 않는다’, ‘가족에 대한 애정은 금지된다’. 친소 관계와 돌봄의 우선순위를 어떻게 다룰지는 별도의 철학적 쟁점이며, 감정의 차이를 없애라는 명령으로 단순화하지 않는다.

### 3. 꾸란의 나눔 — 필요한 것도 함께 물어볼까?

**참고 원전 위치:** 《꾸란》 2:177, 2:215. 제9장 60절(9:60)은 자카트의 수혜 범주를 구별해 설명할 때 추가로 참고한다.

**원전 설명:** 2:177은 믿음·예배·책임 등을 포함한 넓은 의로움의 설명 안에서, 소중히 여기는 재산을 친척·고아·궁핍한 사람·여행자·도움을 청하는 사람 등을 위해 쓰는 일을 다룬다. 2:215도 지출·나눔의 대상들을 이야기한다. 9:60은 자카트와 관련된 수혜 범주를 다룬다. 자카트는 정해진 조건을 가진 종교적 의무이며 자발적인 나눔 일반과 같지 않다. 이 구절들은 공동 프로젝트 상금의 분배 비율을 정해 주지 않는다.

**현대 응용:** 자신에게 필요한 것과 다른 사람에게 필요한 것을 함께 살피는 질문으로 연결한다. 개인의 몫을 결정하는 일, 개인이 자신의 몫에서 나누는 일, 공동 재산을 함께 쓰는 일은 구별한다. 이야기에는 실제 경제 사정에 관한 정보가 없으므로 특정 인물이 더 궁핍하다고 추측하지 않는다.

**아이용 카드:** “이슬람에서는 신앙의 실천으로 도움이 필요한 사람에게 재산을 나누는 일을 중요하게 여겨. 이 가르침에서 출발해 ‘각자에게 필요한 것도 함께 물어볼까?’라고 질문해 보자. 공동으로 받은 돈을 쓰려면, 그 돈을 함께 받은 사람들의 의견도 들어야 해.”

**금지되는 요약:** ‘이슬람의 정답은 가장 가난한 사람에게 상금 전부 주기’, ‘자카트는 모든 돈을 똑같이 나누는 제도’, ‘팀원의 허락 없이 기부해도 된다’. 경전에 있는 기부의 보상 표현을 웹 점수·상금 배율로 옮기지 않는다.

### 4. 기독교의 포도밭 일꾼 비유 — 같은 몫은 언제 불공정할까?

**참고 원전 위치:** 《마태복음》 20:1–16. 첫 절이 하나님 나라에 관한 비유임을 밝힌다.

**원전 설명:** 먼저 고용된 일꾼은 약속한 하루 품삯을 받고, 늦게 고용된 일꾼도 같은 액수를 받는다. 주인의 넉넉함과 먼저 온 이의 불만 등이 드러나는 하나님 나라 비유이다. 현대 임금 정책이나 공동 상금 배분을 명령하는 본문으로 취급하지 않는다. 교파와 해석 전통에 따른 읽기 차이도 있다.

**현대 응용:** ‘처음 약속한 몫’, ‘일한 시간’, ‘넉넉하게 주는 행위’가 충돌할 때 각 인물은 어떻게 느끼는지 묻는다. 비유에서는 주인의 재산을 주인이 지급하고, 이번 이야기에서는 세 사람이 함께 얻은 상금을 논의한다는 차이를 먼저 밝힌다. 돈의 몫과 사람의 가치를 구별하는 질문도 제작진의 응용으로 사용할 수 있다.

**아이용 추가 카드:** “마태복음의 포도밭 일꾼 비유에서는 먼저 온 일꾼과 늦게 온 일꾼이 같은 품삯을 받아. 하나님 나라에 관한 이야기라서 우리 상금의 규칙을 바로 정해 주지는 않아. 처음 약속한 몫과 실제 일한 시간이 다르게 느껴질 때, 각 인물은 어떤 이유를 말할까?”

**금지되는 요약:** ‘기독교는 모든 노동에 동일 임금을 지급하라고 한다’, ‘약속·기여를 따지는 사람은 나쁜 사람이다’, ‘공동 재산을 가진 사람이 마음대로 나눠도 된다’.

이 카드는 첫 영상의 핵심 3카드에 추가되는 선택 자료이다. 전통 소개의 개수를 늘리기 위해 필수 시청 시간을 늘리지 않는다.

## 에피소드 01의 숫자·사실 검수

| 항목 | 확정 설정 또는 제약 |
| --- | --- |
| 상금 | 10만 원, 1칩당 1만 원, 총 10칩 |
| 초기 역할 | 지우: 코드 / 서윤: 그림 / 민호: 테스트·홍보 |
| 반전 1 | 지우는 저장·점수 오류도 수정했다 |
| 반전 2 | 서윤은 색만으로 구분하기 어려운 사용자를 위해 버튼 모양·명도를 다시 디자인했다 |
| 반전 3 | 민호는 버그 8개 발견, 친구 20명의 테스트 의견 정리, 설명 영상 제작 |
| 알려지지 않은 것 | 총 작업 시간, 작업의 객관적 난도, 가정 형편, 종교, 사전 배분 약속의 구체적 내용 |
| 배분 UI | 세 명의 합계 10칩. 3·3·4를 ‘똑같이 나누기’라고 표시하지 않는다 |
| 다른 해법 | 더 작은 단위·공동 사용 등은 생각 노트에 제안 가능 |
| 정답화 방지 | 다수 선택을 정답으로 제시하지 않는다. 수치와 변경 여부로 착함·성숙함·성격을 판정하지 않는다 |

숫자나 반전 설정이 바뀌면 대본·웹·출처 설명을 함께 갱신한다. 서윤의 접근성 수정이 등장하지만, 게임 시제품의 접근성 검증을 실제로 마쳤다는 뜻은 아니다.

## 매 편의 검토 순서

1. 아이에게 실제 의미가 있는 사건인가? 어른의 결론을 유도하는 숨은 문항은 없는가?
2. 새로운 정보는 어떤 판단을 바꿀 수 있는가? 특정 결론으로 몰기 위해 사실을 불균형하게 제공하지 않았는가?
3. 관점마다 원전 설명·현대 응용·해석 한계가 분리되어 있는가?
4. 실제 사생활 공개나 신앙 선택을 요구하지 않는가? 경계와 거절을 존중하는가?
5. 영상 자막·색 이외의 표시·웹 키보드 조작·모바일 사용이 가능한가?
6. 원문·번역·전문 해석 검토와 대상 연령의 실제 이해도 검토를 어느 수준까지 마쳤는가?
7. 완료하지 않은 검증과 아직 제작하지 않은 영상·콘텐츠를 완료했다고 표시하지 않았는가?

검토 결과에는 수행한 일과 남은 일을 그대로 남긴다. 원전·번역 대조, 독립 전문가 검토, 실제 아이의 이해도 검토는 서로 대체할 수 없다.
