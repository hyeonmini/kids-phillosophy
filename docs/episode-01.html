# 01. 우리 게임이 상금 10만 원을 탔다. 누구 돈일까?

상태: 영상 제작용 대본과 웹 연결 설계. 영상 파일·녹음·아동 사용자 검증은 아직 제작·실행하지 않았다.

- 권장 대상: 초등 4~6학년. 초등 저학년은 어른과 함께, 중학생은 약속·권력·평가 기준까지 확장한다.
- 영상 본편: 6분 40초. 웹에서 선택하고 기록하는 시간은 별도이며, 권장 전체 활동 시간은 12~18분이다.
- 주제: 공정함은 하나의 계산법으로 끝나는가? 보이는 일과 숨은 일을 어떻게 평가하는가?
- 로드맵 위치: 4단계 ‘공정함과 책임’의 첫 사건. 01은 파일·제작 식별자이며 로드맵 순서와 달리 첫 구현으로 선택했다.
- 목표: 근거를 확인하고 자신의 판단을 다시 살펴보는 경험을 만든다.
- 완료 조건: 두 번 배분하고 이유를 남기거나, 이유를 쓰기 어렵다고 선택한다. 특정 배분·변경·기부에 점수를 주지 않는다.

## 이야기의 조건

가상의 게임 대회에서 세 친구의 팀이 상금 10만 원을 받았다. 지우는 코드를, 서윤은 그림을, 민호는 테스트와 홍보를 맡았다. 팀은 상금을 어떻게 나눌지 미리 정하지 않았다. 이야기에서는 비용 정산이나 계약 분쟁보다 배분 이유에 집중한다. 실제 팀이라면 대회 규정, 기존 약속, 실제 지출, 보호자와의 협의도 먼저 확인해야 한다.

웹에서는 1만 원짜리 칩 10개를 세 사람에게 나눈다. 이 단위로는 세 명의 금액을 완전히 같게 만들 수 없다. 3·3·4 배분을 동일 배분이라고 부르지 않는다. 더 작은 단위로 나누거나 공동으로 쓰는 제안은 마지막 생각 노트에 적을 수 있다. 웹의 합계 제약과 이야기의 가능한 답을 혼동하지 않는다.

| 캐릭터 | 처음 보이는 역할 | 나중에 공개하는 사실 |
| --- | --- | --- |
| 지우 | 게임 코드를 만들었다 | 플레이어에게 잘 보이지 않는 저장·점수 오류도 고쳤다. 화면에 보이는 기능만이 코드 작업의 전부는 아니다. |
| 서윤 | 캐릭터와 배경을 그렸다 | 색만으로 버튼을 구분하기 어려운 사용자가 있어, 버튼의 모양과 명도까지 다시 디자인했다. |
| 민호 | 테스트하고 홍보했다 | 버그 8개를 발견하고, 친구 20명의 테스트 의견을 정리했으며, 게임 설명 영상을 만들었다. |

이 사실들은 실제 조사 결과가 아니라 이야기를 위해 정한 설정이다. 세 사람의 총 작업 시간·난도·경제적 필요는 알려 주지 않는다. 새로운 정보만으로 특정 비율이 자동 결정되지는 않는다.

녹음 후 전체 길이를 다시 측정한다. 6분 40초는 편집 목표이며, 빠르게 읽어서 맞추지 않는다. 카드 설명이 길게 들리면 영상에서는 핵심 질문을 남기고 자세한 맥락은 웹 출처 영역으로 옮긴다.

## 관점 카드의 연결 규칙

- 원전의 설명과 이 상금 이야기의 응용을 눈에 보이게 나눈다. 원전 위치와 해석 한계는 editorial-guide.md를 따른다.
- ‘기여를 따지는 아리스토텔레스 / 똑같이 나누는 묵자 / 필요한 사람에게 주는 이슬람’처럼 세 개의 계산 공식으로 단순화하지 않는다.
- 등장인물의 종교·가정 형편을 설정하지 않았다. 관점 카드는 세 사람의 실제 신념이나 경제 사정을 대신 설명하지 않는다.
- 도움이 필요한 사람을 고려하는 제안은 돈의 공동 소유와 당사자의 의사를 함께 검토한다. 기부를 활동 완료 조건으로 삼지 않는다.
- 포도밭 비유 추가 카드는 기독교의 하나님 나라 비유를 소개한다. 이 대회 상금을 동일하게 나누라는 지침으로 제시하지 않는다.

## 생각 노트

말·그림·짧은 글 중 편한 형식으로 남긴다. 개인 상황이나 친구 이름을 공개할 필요는 없다.

1. 처음 제안: 지우 __칩 / 서윤 __칩 / 민호 __칩. 내가 중요하게 본 것은 __.
2. 두 번째 제안: 지우 __칩 / 서윤 __칩 / 민호 __칩. 새로 알게 된 것은 __.
3. 내 배분이나 이유가 바뀐 부분 / 그대로인 부분: __.
4. 칩을 더 작게 나누거나 함께 쓸 수 있다면: __.
5. 아직 모르는 사실, 또는 셋에게 묻고 싶은 것: __.
6. 다음 팀 활동을 시작하기 전에 정하고 싶은 약속 한 가지: __.

웹에는 1~3을 기본으로, 4~6을 선택 질문으로 둘 수 있다. 사적인 가족 소득·신앙·친구의 성격을 입력하도록 요구하지 않는다. 노트를 공유할 때도 당사자의 이름과 개인 정보를 먼저 지운다.

## 가족·교실 질문

- 한 사람이 빠졌다면 게임은 어떻게 달라졌을까? 그것만으로 몫을 계산할 수 있을까?
- 눈에 잘 보이는 일과 눈에 잘 안 보이는 일을 어떻게 기록하면 좋을까?
- 일이 시작되기 전에 한 약속이 있다면, 이번 판단은 어떻게 달라질까?
- 가족이나 교실에서 모두가 함께 쓰는 것을 정할 때, 말할 기회는 누구에게 있는가?

어른은 자신의 배분을 모범 답안으로 제시하기보다 “그 이유를 더 듣고 싶어”라고 묻는다. 아이가 선택을 유지하거나, 어른과 다르게 생각하거나, 기록을 건너뛰어도 활동 실패로 평가하지 않는다.

## 현실적인 제작 메모

첫 편은 16:9 화면의 제한된 2D 모션으로 만든다. 캐릭터 3개, 표정 각 3개, 작업 아이콘 6~9개, 칩, 배경 2개, 관점 카드 3개를 재사용한다. 실제 아역 촬영·립싱크·풀 프레임 애니메이션은 초안 범위에 넣지 않는다.

| 작업 | 1인 또는 소규모 직접 제작의 예상 시간 | 산출물 |
| --- | --- | --- |
| 대본 다듬기·문헌 대조 | 3~5시간 | 확정 대본·발음표·출처 노트 |
| 간단한 그림·스토리보드 | 5~8시간 | 캐릭터·아이콘·9장면 콘티 |
| 녹음·음성 정리 | 2~4시간 | 한 명의 내레이션과 캐릭터 대사 |
| 모션·편집·자막 | 8~12시간 | 6분 40초 목표의 본편·SRT 자막 |
| 화면·소리·출처·웹 일치 검수 | 2~4시간 | 검수 기록·수정본 |

합계 20~33시간의 계획 추정이다. 기존 컴퓨터·마이크와 무료 편집 도구를 사용하면 별도 현금 지출 목표는 0~10만 원 안에서 잡을 수 있으나 인건비는 포함하지 않는다. 유료 음악·폰트·녹음 장비·외주 성우가 필요하면 해당 견적을 따로 확인해 예산을 다시 잡는다. 아직 구매·발주한 항목은 없다.

- 모든 대사에 자막을 제공하고, 색·효과음만으로 새로운 사실을 전달하지 않는다. 칩은 수량과 숫자를 함께 표시한다.
- 음악은 목소리를 가리지 않는 수준으로 사용한다. 사용한 그림·음악·폰트의 라이선스를 기록한다.
- 웹은 드래그만으로 조작하게 하지 않는다. 버튼·키보드·스크린리더로 배분하고 현재 합계를 알 수 있어야 한다.
- 검수 순서: 역할·반전 사실 일치 → 칩 합계와 단위 한계 → 출처·종교 맥락 → 자막·접근성 → 실제 대상 연령의 이해도 검토.
- 아동 이해도 검토는 아직 하지 않았다. 실제 파일럿에서는 필요한 보호자·기관 절차를 갖춘 뒤 ‘이야기를 이해했는가, 숨은 일을 기억하는가, 다른 이유를 설명할 수 있는가’를 확인한다. 특정 숫자를 선택했는지로 성공을 판단하지 않는다.

## 공개 전 체크

- 영상은 실제로 제작되었는가? 아직 대본이면 웹에서 대본·스토리보드로 명확히 표시했는가?
- 장면·카드·웹의 역할과 숫자가 모두 일치하는가?
- 원문·번역 대조와 종교·철학 해석 검토가 기록되어 있는가?
- 전체 대본 낭독 시간, 자막 가독성, 모바일 조작, 저장·삭제 동작을 실제로 확인했는가?
- 사용자 검증 전이라면 ‘아이들이 좋아했다’ 등 미확인 성과를 표시하지 않았는가?
